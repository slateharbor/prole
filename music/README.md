# music/

Battle music for the Pokerole DM Toolkit. **One file per music bucket, named by its key** —
the DM app auto-plays these by scene, and broadcasts to players.

Drop audio here with these exact names:

| File | Plays during |
|------|--------------|
| `default.mp3`  | Default / fallback |
| `ambient.mp3`  | Ambient / Travel (walkalong) |
| `wild.mp3`     | Wild Pokemon battles |
| `trainer.mp3`  | Trainer battles |
| `gym.mp3`      | Gym Battle |
| `pvp.mp3`      | PvP |
| `training.mp3` | Training |
| `contest.mp3`  | Contest |
| `survival.mp3` | Fight For Your Life |

Served via jsDelivr:
`https://cdn.jsdelivr.net/gh/countsacula-boop/prole@main/music/{bucket}.mp3`

(.ogg / .m4a work too — just say so and the app URLs get adjusted. You don't need all nine; any you skip just play no music.)
